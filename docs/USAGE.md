# 使用说明

模块入口为“设备借用管理”，包含“设备”“借用申请”和仅设备管理员可见的“待审批”。

## 1. 配置用户角色

系统管理员在“设置 → 用户与公司 → 用户”创建内部用户，按职责授予权限：

| 角色 | 权限配置 | 职责 |
| --- | --- | --- |
| 普通员工 | 内部用户 | 查看设备，创建、查看自己的申请，编辑并提交自己的草稿 |
| 设备管理员 | 内部用户，并授予“设备借用管理 / 设备管理员” | 维护设备，查看全部申请，处理审批、借出和归还 |

设备管理员不需要系统设置权限。新安装不附带业务账号或初始设备，用户密码由系统管理员在本机设置。

## 2. 录入设备

设备管理员进入“设备 → 新建”，填写设备名称、独立设备编号和类别，按需填写描述，保存记录。

一条设备记录对应一台实物。设备编号必须唯一，归档后也不能重复使用。停用设备可通过归档保留历史；归档设备不能用于新的申请，但已借出的设备仍允许办理归还。

## 3. 提交借用申请

员工进入“借用申请 → 新建”，选择设备，填写计划借用日期、计划归还日期和借用理由，保存草稿。

- 申请人由服务端固定为当前登录用户。
- 申请编号自动生成，例如 `EBR/2026/00001`。
- 计划归还日期不能早于计划借用日期，允许同日借还。
- 点击“提交审批”后，状态变为“待审批”，设备、日期和理由等内容冻结。

普通员工只能查看自己的申请，包括设备详情中的关联申请记录。

## 4. 审批与交接

| 当前状态 | 操作人 | 可执行操作 | 结果 |
| --- | --- | --- | --- |
| 草稿 | 申请人 | 提交审批 | 待审批 |
| 待审批 | 设备管理员 | 批准 | 已批准，开始占用设备 |
| 待审批 | 设备管理员 | 拒绝 | 已拒绝，不占用设备 |
| 已批准 | 设备管理员 | 确认借出 | 已借出，继续占用设备 |
| 已借出 | 设备管理员 | 确认归还 | 已归还，释放设备占用 |

设备管理员从“待审批”处理已提交的申请。审批完成的记录自动离开该队列，后续借出和归还操作从“借用申请”进入。

待审批记录加粗并着色；状态标签区分已批准、已借出和已拒绝等状态。待审批入口用于处理现有申请，创建申请请使用“借用申请”入口。

## 5. 设备占用规则

同一设备最多存在一条“已批准”或“已借出”的申请。多条草稿或待审批申请可以同时存在，但第一条申请归还前，其他申请不能再被批准。

当前规则从批准时开始占用，与计划日期是否重叠无关。计划日期不会触发自动借出、自动归还或自动释放占用。

## 6. 查看记录和常见提示

设备详情的“借用申请”页签显示关联记录。员工只能看到自己的申请，设备管理员可以看到全部关联申请。

| 提示或现象 | 处理方式 |
| --- | --- |
| 设备编号已存在 | 使用其他独立编号 |
| 设备已有已批准或已借出的申请 | 待当前占用申请办理归还后，再批准下一条申请 |
| 只有草稿可以编辑 | 已提交申请的内容被冻结；当前版本可重新创建申请 |
| 申请状态已发生变化 | 刷新页面后按最新状态操作 |
| 此申请正在更新 | 稍后刷新并重试 |

所有角色都不能永久删除设备或申请。已拒绝、已归还等历史记录保留用于查询。
